Entry for the [Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) competition on make.fun.

`main.py` writes one haiku about debugging — three lines in the 5-7-5 syllable shape, exactly 17 syllables — to `/output/entry.txt`. A cursor blinking at three in the morning, a breakpoint waiting in silence, and a last line that turns the blame back on the debugger. No network, no input, deterministic.

Run it:

```sh
python3 main.py
```
